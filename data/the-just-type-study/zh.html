2026.07.24 上海 antianti（受邀演出）
2026.10.04 Cedar Land（上海 CPARK，受邀拼盘艺术家） 状态完成 资料系统试听录音（22:51）；Teletype Scene 脚本可下载；2026.10.04 演出海报与现场照（见下）；系统照片（待补拍） 作品简介 这是我为 2026 年 7 月 24 日的演出设计的一套 Eurorack 系统，尺寸 3+1U、64HP，一共八块模块。

核心是一块 Monome Teletype 的 Clone（王凯文制作）。它有自己的一套编程语言，可以用脚本组织音乐；一首曲子的和声、量化与触发都写在脚本里，脚本随页面提供下载。

其余七块：Mannequins Just Friends（数字振荡器，可由 Teletype 经 I2C 数字控制）、Holocene AWMS（Radio、LFO 与 S&H）、Holocene Seiche（Complex Dual Filters）、khiat v.dws（把马特诺音波琴式的拉线位移变成电压输出的控制模块）、sarnesjo 设计的 1U Nearness Mixer（带 panning 的混音）、1U Pico FX（Reverb）、1U 有源 Output 模块。Pico FX 与 Output 来自 fm.things，由我的朋友 qoɔ 制作。

作品动机 这套系统有三个出发点：

第一，学 Teletype。它买了两年，我一直计划学、始终没有开始；可能因为它过于菜单驱动、学习成本高，而且一直不在我的工作流里。

第二，让大部分人能接受。我一直把通俗的可听性放在很低的优先级，所以我的演出往往很难被接受；这里有一部分是我的通俗音乐设计能力不足，也有一部分是我在创作时根本不从可听性出发。

第三，在小系统里做一次 Live Set。我习惯用 24U 104HP 这样的大系统创作，而考虑到我计划去欧洲学习声音艺术，把这样巨大的系统带过去并不现实，我有必要学会在小系统的限制下设计。

灵感溯源 和声脚本是照着 Instruō harmonàig 的思路写的：把和弦内的音高量化出来，让系统自己决定「下一个音可以是什么」。

技术介绍 在这个系统中，我效仿Instruō harmonàig逻辑，设计了一个只需要输入根音即可设计和弦的脚本，并且设计了一个和声进行，让Just Friends的输出3-6根据这个和声进行输出柱式和弦。3-6输出的每个输出之间有细微的时间差，将输出的时间差按照这些接口在Nearness上的Panning关系进行设计，我得到了"从左到右被触发"的柱式和弦。输出1-2为旋律输出，它们的音高为八度关系。旋律的音高由v.dws这款拉环模块输出的电压，输入到Teletype的CV in，使用量化脚本，量化为当前和弦的和弦内音。当输入电压改变时，旋律会被触发，当输入电压长时间不改变时，旋律将会终止。我还设计了一组有节奏的Trigger输出来Ping Seiche的两个Filter，以此设计了打击乐，而AWMS提供了Radio输出、LFO、S&H来帮助这个系统更有呼吸感。

这个系统的Patching是非常简单和一目了然的，Teletype的Script我将会提供在这里，供有需要的人参考和使用。非常抱歉，我没怎么写介绍和注释。 

M:
EVERY 4: $ 2
K O; $ 1
I ER 3 16 K; J ER 17 32 K
IF I: CV 1 N RRND 0 3; TR.P 1
IF J: TR.P 2

I:
JF.MODE 1
JF.VTR 0 V 3
JF.VTR 1 V 2; JF.VTR 2 VV 150
M 50; M.ACT 1
PN.WRAP 0 1; PN.I 0 -1
TR.TIME 1 100; TR.TIME 2 100

1:
X DIV IN 1024
I MOD X 4
J N MUL 12 ADD 2 DIV X 4
C ADD N.C B Z I J
$ 7

2:
T MOD ADD T 1 16
IF EZ ER 2 16 T: BREAK
R PN.NEXT 0; $ 3; $ 6

3:
B R; Z 0
Y WRAP R 0 11
IF EQ Y 7: Z 2
IF EQ Y 11: Z 6
IF EQ MOD Y 7 2: Z 1
IF EQ Y 4: Z 1

4:
L 3 6: JF.TR I 1
DEL 50: $ 5

5:
L 3 6: JF.TR I 0

6:
JF.PITCH 5 N.C R Z 2
DEL 10: JF.PITCH 3 N.C R Z 0
DEL 20: JF.PITCH 4 N.C R Z 1
DEL 40: JF.PITCH 6 N.C R Z 3
$ 4

7:
IF NE X A: $ 8
IF EQ D 1: JF.TR 1 0
IF EQ D 1: JF.TR 2 0
IF GT D 0: D SUB D 1
A X

8:
D 40
JF.PITCH 1 - C N 12
JF.PITCH 2 - C N 24
JF.TR 1 1
JF.TR 2 1
